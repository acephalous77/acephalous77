**[dividual.studio](https://dividual.studio)** — WP-2026-01, *The Matchmaker's Fixed Point*: engagement-optimized matchmaking retrains on the population it just reshaped, and the loop settles at a stable point some distance from the optimum. Alongside it, a validation harness that tests my own estimators against simulated games with the answer planted first, because a model scored on real data has no answer key and can look excellent while being wrong.
